The branch structure on this repo is a bit weird. Different branches implemented different features. This was so that we could demo them easily in the Viva and experiment with new ideas. Breakdown of working branches would be:

broker-implementation: the main distributed component, with a broker and worker nodes that run the simulation concurrently
do-you-bench: benchmarking
its-rishis-fault: an implementation of fault tolerance
fake-halo: halo exchange, but not decoupled
